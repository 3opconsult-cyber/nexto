Inscription par téléphone, façon Airbnb

Popup « Je cherche / Je propose » à l'ouverture, numéro vérifié par code SMS, puis démonstration de la bascule client/pro sur le même compte.

Pure maquette visuelle. Aucun SMS n'est envoyé, aucun compte n'est créé. Rien n'est branché à Supabase ni à un fournisseur SMS.
Déjà réel dans l'app

Le compte à double casquette existe : une fois l'onboarding pro fait, le menu (☰) propose « Passer en mode pro / Revenir en mode particulier » sur le même compte — voir l'écran 4 ci-contre, qui reproduit ce vrai bouton.

Pas encore réel

L'auth par téléphone (écrans 2 et 3). Aujourd'hui le téléphone est un champ texte non vérifié. Passer à un vrai code SMS demande un fournisseur (Twilio ou équivalent) configuré dans Supabase, avec un coût par envoi.
