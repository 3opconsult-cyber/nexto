Décision — piste negative space

Elle tient sur PING, mais une seule fois.

La piste avait été explorée sur SONAR et CONNECT, deux noms écartés. Reprise sur le nom retenu, elle ne donne qu'un résultat : le mot contient déjà son message. PING contient PIN. Le i devient l'épingle plantée sur la carte, et son trou est le point vert du signal — rien n'est ajouté au mot, une lettre est seulement révélée.

L'identité

Deux pièces, deux emplois. Jamais empilées.

Le signe dit l'action — le geste du bouton qui scanne la carte. Le logotype dit la promesse — une épingle plantée à côté de chez vous. Le dispositif n'est ni l'un ni l'autre : c'est l'image de couverture.

Anneaux + point

Le dispositif

La question

Un point d'interrogation dont le point est le signe. La question a pour réponse la marque. Une fois par support, grande, jamais en décoration.

La grille

Trois règles. Le reste en découle.

01
Une seule margeIdentique sur les quatre côtés du support. Elle ne change qu'avec le format, jamais à l'intérieur d'un même support.
02
Tout aligne à gaucheSur cette marge, y compris les images : le crochet du point d'interrogation est calé au pixel sur le bord du texte. Rien n'est centré.
03
Tout espacement vertical est un multiple d'une unitéLa marge vaut deux unités. Aucune valeur d'espacement n'existe en dehors de cette suite.

Corollaires appliqués partout : une seule idée par page, un seul filet par support, un seul accent chromatique. Le vide n'est pas un manque, c'est le sujet.

Acquisition

Chaque support sait ce qu'il a ramené.

Les QR ne portent pas l'URL complète avec ses paramètres : à 120 caractères le code devient trop dense et ne se scanne plus imprimé à 20 mm. Vérifié en décodant les PDF rendus — le QR du sticker prestataire ne passait pas. Ils portent un lien court, résolu côté serveur, qui redirige vers la bonne page avec l'attribution complète.

La cible d'un code se change sans réimprimer. C'est l'intérêt principal : un support qui circule reste utile même si la destination bouge.

Un code ne se supprime jamais tant que des supports imprimés circulent. Un code inconnu redirige vers la carte, pas vers une erreur : quelqu'un qui vient de scanner un flyer dans la rue ne doit pas tomber sur un 404.

Le domaine reste nexto-eta.vercel.app, imprimé tel quel sur les supports. C'est la seule chose du lot qui mériterait d'être tranchée avant d'engager un vrai tirage.

Sources et build : brand/ dans le dépôt nexto. python3 build.py régénère le lot complet. Rendu weasyprint pour les PDF, Chromium pour les visuels écran.
